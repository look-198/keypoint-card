# keypoint-cards 重点卡片

> 把一篇文章的重点句子自动抽出来，生成一组可以直接打印、截图的知识卡片。

这是我的**第一个开源项目**。我是一个大一学生，正在学 Python。我平时读长文章时总需要提取重点，就写了这个小工具——边学边写，欢迎各路前辈指点。

## ✨ 特性

- **零依赖**：只用 Python 标准库，下载即用，不用 pip install 任何东西
- **离线可用**：生成的卡片是一个独立 HTML 文件，双击就能打开
- **可打印**：自带打印样式，导出 PDF 或截图都很干净
- **核心算法简单透明**：词频统计 + 句子打分，100 来行代码，新手也能看懂

## 🚀 快速开始

```bash
# 用示例文章试跑（生成 5 张卡片）
python main.py sample.txt

# 指定卡片数量
python main.py 你的文章.txt 8
```

运行后当前目录会出现 `cards.html`，用浏览器打开即可。

## 🧠 工作原理（一句话版）

> 一篇文章里反复出现的字词组合，就是作者反复强调的概念；包含这些概念的句子，大概率就是重点句。

具体步骤：

1. 按 `。！？；` 等标点把文章切成句子
2. 统计全文的"词频"（中文取相邻两字组合，英文取单词，无需分词库）
3. 每个句子按"包含关键词的平均频率"打分
4. 取分数最高的 N 句，按原文顺序生成 HTML 卡片
